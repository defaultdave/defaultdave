I'm Dave Fleming, a senior frontend engineer. At Disney I built subscription and payment flows across Disney+, ESPN+ and Hulu, serving more than 130 million subscribers, launched a design-token system across React products, and set up the accessibility training program and recurring WCAG reviews. Before that I spent ten years at Viacom building front-end systems for Nickelodeon's sites, including Nick.com and NickJr.com, where I won a Technology & Engineering Emmy Award for resolving launch-critical engineering issues on the Nick App rollout.

Most recently, on contract, I rebuilt checkout for a booking marketplace on Next.js App Router and Stripe Payment Element, and ran the performance work that moved the site's mobile Core Web Vitals into Google's Good range. I work in small slices behind feature flags, and I build my own tooling the same way: vig is the multi-agent Claude Code setup I use for planning, implementation, review and QA, and I used it to build this site. I also release music on Bandcamp, and it has its own page here.
